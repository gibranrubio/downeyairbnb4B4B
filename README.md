# Casa Rubio Home Guide

Static site exported from Carrd and ready for GitHub Pages.

## Deploy
1. Upload `index.html` and the `assets` folder to a GitHub repo.
2. Go to Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /root.
6. Save.

Do not rename or move the `assets` folder unless you update the paths in `index.html`.
